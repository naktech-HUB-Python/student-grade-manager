Student Grade Manager



Project Description



Student Grade Manager is a Python application that allows users to enter student names and grades, calculate academic performance, and generate a summary report.



This project demonstrates the use of Python functions, loops, conditional statements, lists, dictionaries, lambda expressions, and input validation.



Features



\* Accepts multiple student records.

\* Validates student names and student grades.

\* Ensures grades are between 0 and 100.

\* Calculates each student’s average grade.

\* Determines whether a student passes or fails.

\* Identifies the top-performing student.

\* Generates a summary report.



Technologies Used



\* Python 3

\* Windows Command Prompt



How to Run



1\. Download or clone this repository.

2\. Make sure Python 3 is installed.

3\. Open the project folder.

4\. Double-click run\_program.bat on Windows.



Alternatively, run the application from a terminal:



py main.py



Project Files



\* main.py – Contains the Python application source code.

\* run\_program.bat – Starts the application in the Windows command window.

\* README.md – Provides project documentation.
